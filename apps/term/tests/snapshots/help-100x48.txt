keys (any key closes this)
  enter                     send
  alt-enter, ctrl-enter     send into the running turn, not after it
  ctrl-j, shift-enter       new line
  up / down                 move in the text, then through history
  ctrl-a / ctrl-e           start / end of line
  alt-b / alt-f             word left / right
  ctrl-w / ctrl-u / ctrl-k  delete word / to line start / to line end
  pgup / pgdn               scroll the chat (also the mouse wheel; dragging copies text)
  shift-up / shift-down     scroll the chat a line
  ctrl-u / ctrl-d           half page up / down (empty input; ctrl-d quits at the end)
  home / end                top / bottom of the chat (empty input; ctrl-home/end always)
  ctrl-o                    full tool results
  ctrl-t                    show thoughts
  esc                       close menu, dismiss prompt, cancel the running turn
  ctrl-b                    a command running a while: on in the background
  ctrl-c                    clear input; twice to quit
  shift-tab                 approvals: ask / review / edits / auto; in a panel, the previous one
  tab                       complete command, note on a prompt, next panel (the chat first)
  chat (tab)                j/k pick · y copy as markdown · enter: in vim keys (v/V, y) · q
  ctrl-s                    put the draft aside / bring it back
  ctrl-g                    sessions sidebar: focus (up/down, enter, n new chat, esc)
  alt-m, ctrl-1…9, alt-'    mark the chat, show marked chat n (or ctrl-g n), the marks
  ctrl-r                    GitHub issues and pull requests (/github)
  ctrl-x, down              subagents under the prompt: enter opens, x stops (down: empty input)
  diff view                 n/p hunk · h/l/0 sideways · s split/unified · f whole file · q close
  1-9, arrows, enter        answer a prompt or fill in a form: tab, type, space; esc: input
  ctrl-p / ctrl-n           use the buttons and forms above, older first

commands
  /clear                              clear the agent's context, keep the chat
  /new                                start a new session in this directory
  /cd [dir]                           move this session to another directory
  /model [harness] [model]            show or set the model
  /effort [harness] [level]           show or set the reasoning effort
  /mode [harness] [mode]              show or set the agent mode
  /resume [claude|codex]              continue an earlier Claude Code / Codex conversation
  /claude <task>                      give a task to Claude Code
  /codex <task>                       give a task to Codex
  /harness [neo|claude|codex]         switch this session's agent: neo (based on pi), claude, codex
  /approvals [ask|review|edits|auto]  ask, review each edit, accept edits, or auto (no value: next)
  /safesearch [strict|moderate|off]   how much adult content web search may return
  /settings [toggle [on|off]]         turn settings on or off, like Show, don't tell. (UI over text)
